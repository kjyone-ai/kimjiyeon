# 입력 템플릿 (복사용)

### 템플릿 A — 기본형 (이메일 답변)

```
[핵심 조건]
- 채널: 이메일
- 톤: 정중하고 간결하게
- 이번에 바뀐 조건: 없음

[문의 원문]
(수강생 문의를 그대로 붙여넣기)

[수강 정보] ※ 담당자가 학사 시스템에서 확인한 값만 기입, 모르면 "미확인"
- 과정명:
- 총 회차 / 진행 회차:
- 결제 금액:
- 기타(결석일·증빙 여부 등):

[관련 규정] (규정 버전: ____ / 시행일: ____)
(templates/policy_sheet.md에서 관련 조항을 조항 번호와 함께 붙여넣기)

위 규정과 수강 정보에만 근거해 [답변 초안 / 근거 규정 / 확인 필요 항목] 3단으로 작성해줘.
```

### 템플릿 B — 간단형 (카카오톡 빠른 응대)

```
[핵심 조건] 카카오톡 / 5문장 이내 / 따뜻한 톤

[문의 원문]
(붙여넣기)

[관련 규정]
(붙여넣기)

위 규정에만 근거해 3단으로 작성해줘.
```

### 템플릿 C — 수치 빈칸 모드 (무료 모델·규정 개정 직후용)

LLM은 **문장 틀만** 만들고, 금액·날짜 같은 수치는 `[[ ]]` 빈칸으로 남긴다. 담당자가 직접 계산해 채운다.

```
[핵심 조건] 이메일 / 정중 / 수치는 절대 직접 쓰지 말고 [[항목명]] 빈칸으로 남길 것

[문의 원문]
(붙여넣기)

[관련 규정 — 조항 번호와 제목만]
제5조(환불 기준), 제7조(결석 인정)

위 문의에 대한 답변 문장 틀을 만들어줘. 금액·날짜·비율은 [[환불액]], [[제출 마감일]]처럼 빈칸으로 둬.
```

출력 예시
```
안녕하세요, OO아카데미입니다. 문의 주셔서 감사합니다.
현재 진행 회차 기준으로 규정 제5조에 따라 [[환불액]]원이 환불됩니다.
결석은 진료확인서를 [[제출 마감일]]까지 보내 주시면 출석으로 인정됩니다(제7조).
```
→ 담당자가 `[[ ]]`만 채워서 발송. 수치를 모델이 만들지 않으므로 **수치 환각이 구조적으로 0**이 된다.
